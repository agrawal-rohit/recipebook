---
title: Recipebook
description: Declarative framework for authoring and sharing any kind of files from a registry you control.
---

Recipebook installs reusable project-setup items from **external** registries — one item at a time — into a project you already have.

It is not a UI component catalog, not a package manager, and not a fixed `create-*` template. Registries define their own item types (configs, components, themes, agent skills, and more), with optional conditions, packs, dependencies, and lifecycle hooks.

## Quickstart

Point Recipebook at a registry, then add an item:

```bash
npx recipebook configure set https://example.com/registry.json
npx recipebook add testing-configuration
```

Or pass a source for a single run:

```bash
npx recipebook --registry https://example.com/registry.json add testing-configuration
```

You can also set `RECIPEBOOK_REGISTRY`.

## What you get

- **Conditions & packs** — adapt the same item per prompts and environment
- **Lifecycle hooks** — `beforeWrite` / `afterInstall` around file installation
- **Safety** — remote scripts never execute; local hooks are sandboxed; overwrites are prompted
